## Release actions still requiring the owner

- Review every Critical `FAIL` and Warning `WARN` in the DQ report with the source owner before any production use.
- Personalize the phase report templates with your actual name, repository URL, screenshots and explanation after running the project and understanding the output.
- Create/use your private GitHub repository, commit the project, and add the program reviewer account only if instructed by the program.
- If the program requires production release, choose a host, configure access/security, deploy, smoke-test and record the public/private URL. This local package does not claim cloud deployment.
- Upload the required submission artifact through the program's own portal; that cannot be performed from this repository.
