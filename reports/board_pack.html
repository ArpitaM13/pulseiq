Operational notes and limitations

  • All 33 worksheets are ingested into the raw schema, including dictionaries, catalogues, and reference sheets.
  • The supplied source already contains a star-schema extract; the warehouse schema mirrors business and reference tables, enforces verified primary keys, and records relationship/orphan checks, while staging stores clean/quarantined core rows.
  • Metric views suppress values below their documented minimum group size. The risk page only shows department aggregates, not named employees.
  • Forecast error is only calculable when a forecast period overlaps an actual headcount period. An empty M28 view means no overlapping actuals in the current fixture, not a zero error.
  • This build is a local release candidate. External production deployment, private GitHub access, and programme-site submission still require the user's accounts and approval.
